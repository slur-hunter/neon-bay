Neon Bay is an original open-world crime game: explore a neon coastal city on foot and by car, steal cars, dodge the police as your wanted level rises, run missions for the Bay's crews, and save your progress. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No network requests: the game is plain static files under game/.
